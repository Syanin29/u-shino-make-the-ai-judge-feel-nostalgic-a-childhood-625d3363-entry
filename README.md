# Twelve Rice Balls in a Tin

[![make.fun · u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363](https://make.fun/badge/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363.svg)](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363?utm_source=github&utm_medium=readme&utm_campaign=u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363)

One single sentence, at most 280 characters, recalling a childhood memory.
`main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

> Every August, Grandma packed twelve rice balls in a tin for my train home, and I ate eleven on the way, saving the last one until the fields were gone, because then the summer was over.

## Run

```sh
python3 main.py
```

Stdlib only. Deterministic: every run writes the same bytes.
